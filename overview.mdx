# Product Overview

PersonaOS is a personal publishing platform with a public portfolio, a private dashboard, connected-interest views, and an optional 3D presentation.

## What it includes

- **Public profile:** portfolio, résumé, projects, writing, and personal pages.
- **Dashboard:** private profile and content editing, publishing controls, and integration settings.
- **Connected interests:** cached culture, football, and competitive-programming data when providers are configured.
- **Daily practice:** backend-managed competitive-programming challenges and contest schedules.
- **3D experience:** a separate stadium-based renderer built from a published profile snapshot.
- **Static export:** a downloadable archive of published site pages for self-hosting.

## How the parts fit

The Next.js frontend renders the public site and dashboard. An Express API on Bun owns authentication, content validation and publication, provider access, and storage operations. Supabase provides identity, PostgreSQL, and object storage; Drizzle manages database queries and migrations. The separate Vite 3D app loads a backend-generated snapshot and provides a content-only fallback.

Markdown is the authored content format. The backend keeps document files in Supabase Storage and indexes ownership and publication status in PostgreSQL. Only published documents and explicitly enabled integration data are returned for public rendering.
